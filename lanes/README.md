# lanes: headless runners for the non-Claude model lanes (dsh)

- `sol61-run.sh` / `luna-run.sh` / `ds-run.sh <prompt-file> <done-file> [max-secs]`: run one headless dsh task
  (gpt-6.1-sol, gpt-6-luna, DeepSeek flash) in the current directory and stop it once it writes `<done-file>`
  (dsh headless never exits by itself). Log: `<done-file>.log`. Each model must be declared in its `*.patch.yml`
  (generated by osnova-product's `bin/lane`), or dsh answers UNKNOWN_MODEL.
- `usage.sh`: Claude weekly/5h usage. `codex-usage.sh`: Codex (Sol/luna6) 5h/weekly usage and reset times.
- One Sol run at a time on this box (they share one dsh home). Runners `rm -f` the done-file first, so never make
  a done-file a symlink.
Moved here from `~/lab/2026-10-orchestrator/bin` on 2026-10-22; the old paths are symlinks to these files.
